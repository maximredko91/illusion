## Что это

Иллюзион — приложение для просмотра личной видеотеки (фильмы, сериалы,
мультфильмы), хранящейся на домашнем NAS/сервере по протоколу SMB.
Библиотека сканируется и индексируется локально по Kodi/tinyMediaManager-совместимой
структуре папок и `.nfo`-файлам — без сторонних облачных сервисов и без
предзагрузки файла целиком перед просмотром.

Разработано для личного домашнего использования; выложено в открытый
доступ на случай, если кому-то пригодится код или сама идея.

## Возможности

- **Стриминг напрямую с SMB** — кастомный Media3 `DataSource` поверх
  [smbj](https://github.com/hierynomus/smbj), позиционные чтения без
  локальной копии файла, перемотка работает как при обычном стриминге.
- **Локальная библиотека**: сканирование SMB-источников, разбор `.nfo`,
  постеры/фанарты, актёры/режиссёры, коллекции, похожие тайтлы, фильмография
  по актёру или режиссёру. Сканирование запускается вручную (по расписанию
  ничего не крутится в фоне); если на NAS появились новые файлы, на главном
  экране показывается баннер с предложением обновить библиотеку.
- **Плеер**: жесты (свайп-перемотка, громкость/яркость), превью кадров на
  перемотке, переключение аудиодорожек и субтитров, внешние субтитры
  (`.srt`/`.ass`/`.vtt`), настройка их цвета/размера/подложки,
  Picture-in-Picture, автовоспроизведение следующей серии, ручная разметка
  заставки и титров с пропуском, таймер сна, блокировка управления,
  соотношение сторон, скорость воспроизведения, диагностика видео
  (кодек, HDR/Dolby Vision, битрейт), настраиваемый размер буфера
  (Авто/Увеличенный/Максимальный — реже буферизация на высокобитрейтных
  файлах за счёт памяти и старта).
- **Внешний плеер** (опционально, в настройках) — вместо встроенного можно
  выбрать любое стороннее приложение; локальный HTTP-мост на 127.0.0.1
  отдаёт файл с NAS как обычный `http://`-поток с поддержкой перемотки
  (`Range`), так что подходит любой видеоплеер, а не только те немногие,
  что умеют `smb://` напрямую.
- **Трейлеры** — локальный файл `<видео>-trailer.ext` рядом с фильмом
  подхватывается при сканировании и играет из карточки.
- **Офлайн-загрузки** с докачкой и восстановлением после сбоя сети (вместе
  с субтитрами), сезон целиком одной кнопкой.
- **Избранное, история просмотров, поиск** (с ранжированием по названию и
  голосовым вводом), **теги**, сортировка и фильтры по жанру/году/стране.
- **Material You** + смена темы (день/ночь/чёрная/системная), выбор
  акцентного цвета, альтернативные значки приложения, edge-to-edge UI.
- **Профиль производительности** (Авто/Максимум/Экономичный) — один
  переключатель на анимации, шейдер резкости, градиенты и вибрацию;
  «Авто» сам определяет слабое устройство.
- **Поддержка Android TV**: отдельный режим интерфейса на
  `androidx.tv:tv-material`, полная навигация с пульта/D-pad, настраиваемый
  отступ от края экрана под overscan телевизора.
- **Бэкап/восстановление** источников, избранного и истории.
- **GPU-шейдер резкости** для картинки через Media3 Effects.
- **Управление кешем**: лимиты на кеш постеров и фанартов по отдельности,
  предзагрузка постеров, очистка по частям; полный сброс приложения.
- **Отчёты о сбоях** — после падения приложение предлагает отправить лог
  разработчику (никуда не уходит само, только через системный «Поделиться»).

## Требования к медиатеке

Ожидается Kodi/tinyMediaManager-совместимая структура:

```
Movies/
  Драма/
    Побег из Шоушенка (1994)/
      Побег из Шоушенка (1994).mp4
      Побег из Шоушенка (1994).nfo
      poster.jpg
      fanart.jpg
Shows/
  Сериал/
    tvshow.nfo
    poster.jpg
    Season 01/          (или «Сезон 1»)
      S01E01.mp4
      S01E01.nfo
      S01E01.srt
```

Рядом с видео могут лежать внешние субтитры (`.srt`, `.ass`, `.vtt`) и
трейлер (`<имя видео>-trailer.mp4` или просто `trailer.mp4`) — и то и другое
подхватывается при сканировании. Папка с припиской `(Коллекция)` в названии
собирает лежащие внутри части фильма в одну карточку.

Файлы опознаются не по имени, а по содержимому (источник + размер + выборка
байт), поэтому переименование файла на NAS не теряет прогресс просмотра и
отметку «избранное».

## Технологии

- Kotlin, Jetpack Compose / Material3
- Media3 (ExoPlayer) с кастомным SMB `DataSource`
- Room, DataStore
- WorkManager (сканирование библиотеки, загрузки, скачивание обновлений)
- [smbj](https://github.com/hierynomus/smbj) — Java-клиент SMB2/3
- Никакого DI-фреймворка — все синглтоны собираются вручную в
  `IllusionApplication` (осознанное решение в пользу простоты)

## Сборка

```bash
git clone https://github.com/maximredko91/illusion.git
cd illusion
./gradlew assembleDebug
```

Опциональные ключи в `local.properties` (не обязательны для базовой сборки):

| Ключ | Назначение |
|---|---|
| `illusion.tmdb.apiKey` | Скрапер метаданных для служебного экрана «Добавление медиа» |
| `illusion.ffmpegExtension.aarPath` | Локально собранное FFmpeg-расширение Media3 (DTS/AC3/TrueHD) — см. `scripts/build_ffmpeg_extension.sh` |
| `illusion.devAccess.password` | Фиксированный пароль для служебного экрана добавления медиа |
| `illusion.signing.*` | Данные keystore для подписанной release-сборки |

## Обновления

Приложение проверяет [GitHub Releases](https://github.com/maximredko91/illusion/releases)
этого репозитория и предлагает обновиться внутри приложения: показывает
список изменений, скачивает `.apk` в фоне и запускает системную установку —
без похода в браузер. Если проверка не удалась (нет интернета, GitHub
недоступен), это явно отличается от «у вас последняя версия», а не молчаливо
считается тем же самым.

Автопроверка запускается при старте приложения с настраиваемым интервалом
(Настройки → «Автопроверка обновлений»): раз в сутки, раз в неделю, раз в
месяц (по умолчанию) или отключена. В любой момент можно проверить вручную —
Настройки → «Проверить обновления».

Найденное обновление не навязывается: можно скачать и установить сразу,
отложить («Позже» — предложение появится снова при следующей проверке) или
пропустить именно эту версию («Пропустить версию» — не предложится повторно,
следующая версия предложится как обычно).

Чтобы релиз подхватился автоматически, при публикации на GitHub:
- **Тег** должен содержать `versionCode` сборки (например, `v70` или просто
  `70`) — именно по нему приложение сравнивает версии, а не по имени.
- Сборка производит по одному `.apk` на каждую архитектуру процессора
  (`splits.abi` в `app/build.gradle.kts`) — к релизу нужно приложить **все**
  получившиеся `.apk`-файлы, и в имени каждого должно быть название его
  архитектуры (`arm64-v8a`/`armeabi-v7a`), например, `illusion-81-arm64-v8a.apk` —
  именно по этой подстроке в имени приложение выбирает свой файл
  (`UpdateChecker.selectApkForDevice`). Один-единственный безымянный `.apk`
  (старая схема) тоже по-прежнему работает — он просто предлагается всем
  устройствам без выбора. Каждый файл — release-сборка, подписанная одним и
  тем же ключом от версии к версии (иначе Android откажется ставить
  обновление поверх, не удалив приложение).
- Черновики (draft) и pre-release игнорируются.

Само по себе это не убирает системное предупреждение Android об установке
не из Google Play — при первом обновлении система один раз попросит явно
разрешить приложению «установку неизвестных приложений» (Настройки →
Приложения → Особый доступ). Это осознанная защита ОС, обойти её
технически нельзя ни для одного APK не из Play Store.

**Обязательные обновления.** Первая строка тела GitHub-релиза может быть
маркером `[MANDATORY]` или `[ОБЯЗАТЕЛЬНОЕ]` (регистр не важен) — тогда диалог
обновления теряет кнопки «Позже»/«Пропустить версию» и не закрывается тапом
мимо, пока обновление не будет установлено. Маркер вырезается из текста,
который видит пользователь.

**Локальный источник обновлений** (альтернатива GitHub Releases) —
Настройки → источник обновлений → «Локально»: приложение проверяет
`manifest.json` + `.apk`-файлы, лежащие на одном из уже настроенных
SMB-источников (папка `IllusionUpdates/`), вместо интернета. Публикация —
`scripts/publish_local_update.ps1` (без секретов, безопасно коммитить) плюс
собственный wrapper-скрипт с реальными данными NAS, который пользователь
держит у себя и не коммитит.

## Сознательно не реализовано

- **Chromecast/DLNA** — сам HTTP-мост уже есть (используется для внешнего
  плеера, см. выше), но он слушает только `127.0.0.1`; для Chromecast нужно
  слушать реальный IP в локальной сети плюс полноценная интеграция Cast SDK
  (обнаружение устройства, кнопка Cast, управление сессией) — заметный объём
  работы, отдельно не делался.
- **Dolby Vision Profile 7 (FEL)** — enhancement-layer недоступен через
  Java-экстракторы Media3 ни на одном устройстве; архитектурное ограничение,
  не баг конкретного плеера. Приложение честно показывает диагностику вместо
  попытки композитинга.
- **Автоопределение заставки по аудиоотпечатку** — сейчас ручная разметка,
  автоматика отложена как отдельная DSP-задача.

## Известное ограничение

Файлы с очень большой Cues-таблицей (например, ремуксы с 4K UHD Blu-ray с
десятками глав и множеством дорожек) могут зависать в буферизации навсегда
из-за особенности `MatroskaExtractor` из Media3, а не проблемы SMB/сети.
Приложение само определяет это при первом воспроизведении (30 секунд без
прогресса) и переключает конкретно этот файл в режим без перемотки — файл
начинает играть, но перемотка на нём не работает. Затрагивает только такие
файлы, не приложение целиком.
