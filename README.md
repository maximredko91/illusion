## Что это

Личная видеотека (фильмы, сериалы, мультфильмы) лежит на домашнем сервере по
SMB. Иллюзион сканирует её, строит локальный каталог по
Kodi/tinyMediaManager-совместимым `.nfo` и папкам — и играет файл потоком, не
копируя его на телефон. В интернет приложение ходит только за обновлением
самого себя и, отдельно, за метаданными на служебном экране добавления медиа.

Писалось для себя; выложено на случай, если пригодится код или идея.

## Быстрый старт

1. Поставьте `.apk` из [Releases](https://github.com/maximredko91/illusion/releases)
   (файл с вашей архитектурой — `arm64-v8a` почти всегда).
2. При первом запуске добавьте SMB-источник: адрес сервера, шара, логин и
   пароль, корневая папка. Кнопка «Проверить подключение» скажет, что не так,
   если что-то не так.
3. Дождитесь сканирования — дальше приложение работает офлайн, с локальным
   каталогом.

На Android 15+ система отдельно спросит разрешение на доступ к локальной
сети: без него SMB-соединение просто молча не устанавливается.

## Возможности

### Библиотека

- Несколько SMB-источников, разбор `.nfo` (постеры, фанарты, актёры,
  режиссёры, студии, рейтинги, коллекции), четыре раздела: фильмы, сериалы,
  мультфильмы, мультсериалы.
- Сканирование только вручную — ничего не крутится в фоне по таймеру. Если на
  NAS появились новые файлы, на главном экране появляется баннер с
  предложением обновить каталог. Повторное сканирование пропускает
  неизменившиеся файлы.
- Файл опознаётся по содержимому (источник + размер + выборка байт), а не по
  имени: переименование на NAS не теряет ни прогресс просмотра, ни избранное.
- Поиск с ранжированием по названию и голосовым вводом, теги, сортировки и
  фильтры по жанру/году/стране, избранное, история, похожие тайтлы,
  фильмография по актёру и режиссёру.
- Бэкап и восстановление источников, избранного и истории.

### Плеер

- Стриминг с SMB через собственный Media3 `DataSource` с упреждающим чтением
  на 1 МиБ — 4K-ремуксы не захлёбываются на перемотке и не буферизуются
  каждые несколько секунд.
- Жесты (перемотка свайпом, громкость и яркость по краям), превью кадров на
  полосе перемотки, PiP, таймер сна, блокировка управления, скорость,
  соотношение сторон, автопереход к следующей серии.
- Аудиодорожки и субтитры, включая внешние `.srt`/`.ass`/`.vtt` рядом с
  видео, с настройкой цвета, размера и подложки.
- Разметка заставки и титров с кнопкой пропуска. Заставку можно **найти
  автоматически по звуку**: приложение сравнивает акустические отпечатки
  начала этой и соседней серии (собственное БПФ, хеш на каждые 64 мс),
  находит общий фрагмент и проставляет метки всему сезону.
- **Выбор декодера** прямо в плеере: Авто / Аппаратный / Программный. Порядок
  декодеров меняется на лету, позиция сохраняется — помогает, когда
  аппаратный декодер рисует артефакты.
- Диагностика: какой кодек, какой именно декодер создан, HDR и профиль Dolby
  Vision, битрейт, размер буфера (Авто/Увеличенный/Максимальный).
- GPU-шейдер резкости для мягких старых рипов. На видео, которое декодирует
  встроенный FFmpeg, резкость считается самим декодером — результат тот же.

### Форматы, которых обычно не хватает

В приложение встроена собственная сборка FFmpeg (LGPL, динамические `.so`,
собираются в GitHub Actions):

- **Видео**: DivX/XviD (MPEG-4 ASP), MS-MPEG4, VC-1, WMV1–3, MPEG-1/2 —
  там, где системный декодер рассыпается на макроблоки или его просто нет.
- **Аудио**: DTS, TrueHD, WMA v1/v2/Pro, плюс AC3/E-AC3 запасным вариантом.
  Системный декодер и HDMI-passthrough имеют приоритет: FFmpeg берёт только
  то, что больше некому декодировать.
- **`.wmv`** разбирается собственным ASF-экстрактором — стриминг, буферизация
  и перемотка по Simple Index остаются за Media3.

### Телевизор и другие приложения

- **Трансляция на ТВ**: Google Cast (Chromecast, Android TV, Xiaomi TV Box) и
  DLNA-рендереры. Файл уходит с NAS через локальный HTTP-мост приложения,
  доступ закрыт одноразовым токеном в ссылке; на телефоне остаются пауза,
  перемотка и остановка, прогресс просмотра пишется как обычно.
  Перекодирования нет — формат должен поддерживаться самим приёмником.
- **Внешний плеер**: вместо встроенного можно выбрать любое стороннее
  приложение — тот же мост отдаёт файл как обычный `http://`-поток с
  поддержкой `Range`, так что подходит не только VLC/MX Player с их
  собственными SMB-клиентами.
- **Офлайн-загрузки** с докачкой после обрыва сети, вместе с субтитрами,
  сезон целиком одной кнопкой.

### Интерфейс

- Material You, темы (день/ночь/чёрная/системная), выбор акцентного цвета,
  альтернативные значки приложения, edge-to-edge.
- **Режим Android TV**: боковая навигация, увеличенные карточки под
  просмотр с дивана, полная навигация с пульта, настраиваемый отступ под
  overscan.
- **Профиль производительности** (Авто/Максимум/Экономичный) — один
  переключатель на анимации, шейдер резкости, градиенты и вибрацию; «Авто»
  сам определяет слабое устройство.
- Управление кешем: раздельные лимиты на постеры и фанарты, предзагрузка,
  очистка по частям, полный сброс приложения.
- После падения приложение предлагает отправить лог разработчику — само
  никуда ничего не отправляет, только через системное «Поделиться».

## Требования к медиатеке

Ожидается Kodi/tinyMediaManager-совместимая структура:

```
Movies/
  Драма/
    Побег из Шоушенка (1994)/
      Побег из Шоушенка (1994).mp4
      Побег из Шоушенка (1994).nfo
      poster.jpg
      fanart.jpg
Shows/
  Сериал/
    tvshow.nfo
    poster.jpg
    Season 01/          (или «Сезон 1»)
      S01E01.mp4
      S01E01.nfo
      S01E01.srt
```

Рядом с видео могут лежать внешние субтитры (`.srt`, `.ass`, `.vtt`) и
трейлер (`<имя видео>-trailer.mp4` или просто `trailer.mp4`) — и то и другое
подхватывается при сканировании. Папка с припиской `(Коллекция)` в названии
собирает лежащие внутри части фильма в одну карточку.

## Обновления

Приложение само следит за [GitHub Releases](https://github.com/maximredko91/illusion/releases):
показывает список изменений, скачивает `.apk` в фоне и запускает системную
установку. Неудачная проверка честно отличается от «у вас последняя версия».

- Интервал автопроверки — Настройки → «Автопроверка обновлений»: раз в сутки
  (по умолчанию), в неделю, в месяц или выключено. Плюс ручная проверка,
  которая интервал игнорирует и всегда ходит в сеть.
- Раз в сутки проверка идёт и в фоне: о новой версии приходит уведомление,
  открывать приложение для этого не нужно.
- Обновление не навязывается: «Позже» или «Пропустить версию». Исключение —
  релиз, у которого первая строка описания `[MANDATORY]` или
  `[ОБЯЗАТЕЛЬНОЕ]`: тогда диалог не закрывается, пока не обновитесь (сам
  маркер из текста вырезается).
- **Локальный источник** (Настройки → источник обновлений → «Локально») —
  приложение берёт `manifest.json` и `.apk` из папки `IllusionUpdates/` на
  одном из уже настроенных SMB-источников, вместо интернета. Публикация —
  `scripts/publish_local_update.ps1`.

Системное предупреждение Android об установке не из Google Play никуда не
девается: при первом обновлении система один раз попросит разрешить
«установку неизвестных приложений». Обойти это нельзя ни одному APK вне
Play Store.

<details>
<summary>Как публиковать релиз, чтобы приложение его подхватило</summary>

- **Тег** должен содержать `versionCode` сборки (например, `v153` или `153`) —
  сравнение идёт по нему, а не по названию релиза.
- Сборка даёт по одному `.apk` на архитектуру (`splits.abi`) — приложите к
  релизу **все**, и в имени каждого должна быть его архитектура
  (`arm64-v8a` / `armeabi-v7a`): именно по этой подстроке приложение выбирает
  свой файл (`UpdateChecker.selectApkForDevice`). Один безымянный `.apk` тоже
  работает — он просто предлагается всем.
- Все сборки подписываются одним ключом от версии к версии, иначе Android
  откажется ставить обновление поверх.
- Черновики и pre-release игнорируются.

</details>

## Сборка

```bash
git clone https://github.com/maximredko91/illusion.git
cd illusion
./gradlew assembleDebug
```

Нативные библиотеки FFmpeg уже лежат в репозитории по ABI — локально их
собирать не нужно (и не получится на Windows без MSYS2/WSL). Пересобираются
они вручную запуском workflow `.github/workflows/ffmpeg-android.yml`.

Опциональные ключи в `local.properties`, ни один не нужен для обычной сборки:

| Ключ | Назначение |
|---|---|
| `illusion.tmdb.apiKey` | Метаданные для служебного экрана «Добавление медиа» (ключ можно ввести и прямо в приложении) |
| `illusion.devAccess.password` | Фиксированный пароль для того же служебного экрана |
| `illusion.signing.*` | Keystore для подписанной release-сборки |

## Технологии

- Kotlin, Jetpack Compose / Material3
- Media3 (ExoPlayer) с собственными `DataSource` (SMB), экстрактором ASF и
  декодерами на FFmpeg через JNI
- Room, DataStore, WorkManager
- Google Cast SDK и собственный SSDP/UPnP-клиент для DLNA — без сторонних
  UPnP-библиотек
- [smbj](https://github.com/hierynomus/smbj) — Java-клиент SMB2/3
- Никакого DI-фреймворка: все синглтоны собираются вручную в
  `IllusionApplication` — осознанное решение в пользу простоты

## Ограничения

- **Перекодирования нет.** На телевизор файл уходит как есть, поэтому
  трансляция ограничена тем, что умеет приёмник (у стандартного
  Cast-приёмника это прежде всего H.264/AAC). Транскодер не планируется.
- **Dolby Vision Profile 7 (FEL)**: enhancement-layer недоступен через
  Java-экстракторы Media3 — это архитектурное ограничение, а не баг
  конкретного устройства. Приложение показывает диагностику и предупреждение
  вместо попыток композитинга.
- **Файлы с огромной таблицей Cues** (ремуксы 4K UHD Blu-ray с десятками
  глав и множеством дорожек) умеют навсегда зависать в буферизации — это
  особенность `MatroskaExtractor` из Media3, не сети и не SMB. Приложение
  определяет это при первом воспроизведении (30 секунд без прогресса),
  запоминает файл и дальше открывает его в обход: таблица Cues читается
  отдельным соединением и подставляется плееру как обычная карта перемотки.
  Файл играет, перемотка работает, остальные файлы не затронуты.
