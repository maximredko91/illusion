Иллюзион вышел из беты.

После 110 бета-сборок приложение считается стабильным: библиотека с NAS, потоковый плеер, встроенный FFmpeg для старых и редких форматов, трансляция на телевизор через Google Cast и режим Android TV.

**Что изменилось по сравнению с beta110**
- Номер версии теперь 1.0.0. Дальше обычная нумерация: 1.0.1, 1.1.0 и так далее.
- Мелкие правки по замечаниям lint в плеере и настройках, на поведение они не влияют.

**Экспериментально (работает, но не проверено на реальных файлах или устройствах)**
- Звук DTS и TrueHD, видео WMV3/VC-1, звук WMA Pro.
- Трансляция по DLNA (Google Cast проверен).
- Автопоиск заставки по звуку.

**Известные ограничения**
- Google Play Защита может предупреждать при установке каждой новой версии: приложения нет в Play, и отключить это из кода нельзя.
- На HyperOS обновление ставится через обычный системный установщик, без тихой установки.
- Dolby Vision Profile 7 показывается только базовым слоем.

Ставьте APK под свою архитектуру, почти всегда это `arm64-v8a`.
