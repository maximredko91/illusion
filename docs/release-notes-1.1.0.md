**Автоматические метки — новый блок в карточке фильма и сериала**

Приложение само находит заставку, титры и сцены после титров. Раньше часть этого была спрятана в панели плеера; теперь всё собрано на экране описания, с пояснением и ходом поиска.

- **Заставка сериала** ищется по звуку сразу по всем сезонам, около 20 секунд на сезон.
- **Титры сериала** — новое. Ищутся по звуку последних минут серий и ставятся каждой серии отдельно. Если финальная музыка в каждой серии своя, титры находятся по картинке.
- **Сцены после титров у фильмов** — новое. Ищутся по картинке, около 20 секунд на фильм. Сцен может быть несколько; во время титров плеер предлагает перейти к ближайшей.
- **После сканирования библиотеки** заставка в сезонах с новыми сериями ищется сама, в фоне. Отключается в настройках рядом с пересканированием.

**Плеер**
- В панели ⚙ остались только ручные отметки, она стала короче.
- Отметка сцены после титров теперь добавляет сцену, а не заменяет прежнюю.
- Плавный уход в «картинку в картинке» после поворота экрана.

**Чего автопоиск не умеет**
- Титры на цветном фоне или поверх видео не распознаются — для них остаётся ручная отметка.
- Сериалам нужны `.nfo` с номером сезона.

**Экспериментально, как и раньше**
- Видео WMV3/VC-1 и звук WMA Pro.
- Трансляция по DLNA (Google Cast проверен).
